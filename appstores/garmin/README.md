# PulseTime: Garmin

Connect IQ port of PulseTime. The app project lives in `pulsetime/`
(see `pulsetime/README.md`) - a device app with a glance and one published
complication for compatible watch faces; `scripts/build-venu2s.sh` builds
`dist/pulsetime-venu2s.prg` (and, with `--harness`, the fixture test app).
`dist/` is build output and is gitignored.
